# Сервис управления рассылками

Веб-сервис для создания и управления email-рассылками. Приложение позволяет пользователям хранить базу получателей, создавать сообщения и формировать рассылки с указанием времени начала и окончания отправки.

Основная задача проекта — предоставить удобный интерфейс для управления рассылками и отслеживания результатов их отправки.

## Возможности

- регистрация пользователей;
- подтверждение email;
- авторизация;
- восстановление пароля;
- управление получателями;
- управление сообщениями;
- управление рассылками;
- ручная отправка рассылок;
- история попыток отправки;
- статистика;
- роли пользователей и менеджеров;
- блокировка пользователей;
- отключение рассылок менеджером;
- кеширование.

## Пользователи и права доступа

В системе предусмотрено разграничение доступа.

**Обычный пользователь** может управлять своими получателями, сообщениями и рассылками, а также просматривать статистику своих рассылок.

**Менеджер** имеет доступ к просмотру пользователей, получателей и рассылок всех пользователей сервиса. Менеджер также может блокировать пользователей и отключать рассылки.

## Работа с рассылками

Для каждой рассылки задаются:

- дата и время начала отправки;
- дата и время окончания отправки;
- сообщение;
- список получателей.

Статус рассылки определяется автоматически в зависимости от текущего времени:

- **«Создана»** — время начала ещё не наступило;
- **«Запущена»** — текущее время находится в разрешённом интервале отправки;
- **«Завершена»** — время окончания уже прошло.

При отправке каждого сообщения система сохраняет информацию о попытке, её результате и ответе почтового сервера.

Таким образом, сервис объединяет управление клиентской базой, сообщениями и рассылками в одном приложении и позволяет отслеживать результаты отправки электронных писем.
